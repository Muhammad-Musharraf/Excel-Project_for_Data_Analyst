# 🛍️ Vrinda Store — Data Analysis Using Excel

A comprehensive data analysis project built entirely in Microsoft Excel, using real-world retail sales data from **Vrinda Store**. The project walks through the full analyst workflow — from raw data to actionable business insights — using only native Excel features.

---

## 📌 Project Overview

This project simulates a real-world data analyst task: taking messy, raw sales records and transforming them into a clean, insightful dashboard. It covers the entire pipeline of data work — cleaning, structuring, analyzing, and visualizing — making it a strong portfolio piece for anyone building or demonstrating Excel-based analytics skills.

---

## 📂 Repository Contents

| File | Description |
|------|-------------|
| `Vrinda Store Data Analysis.xlsx` | Main Excel workbook containing raw data, cleaned data, pivot tables, charts, and the final dashboard |

---

## 🔍 Key Features

### 🧹 Data Cleaning
- Handled missing values and inconsistencies in the raw dataset
- Standardized column formats (dates, categories, numeric fields)
- Removed duplicates and corrected data entry errors

### 📊 Data Analysis
- Built **Pivot Tables** to summarize sales by category, region, channel, and time period
- Calculated key business metrics including total revenue, order counts, and average order value
- Identified top-performing product categories and customer segments

### 📈 Data Visualization
- Created dynamic **charts** (bar, line, pie) to highlight trends and distributions
- Visualized monthly sales performance and year-over-year comparisons
- Segmented data by gender, age group, and sales channel (e.g., Amazon, Flipkart, Meesho)

### 💡 Insights Derived
- Which months generated the highest revenue
- Top states and regions by sales volume
- Most popular product categories
- Customer demographics driving the most orders
- Channel-wise performance breakdown

## 🛠️ Tools & Techniques Used

- **Microsoft Excel** (no external tools or plugins required)
- Pivot Tables & Pivot Charts
- VLOOKUP / IF / TEXT functions for data transformation
- Data Validation and Conditional Formatting
- Slicers for interactive filtering

## 🚀 Getting Started

1. **Clone or download** this repository
2. Open `Vrinda Store Data Analysis.xlsx` in **Microsoft Excel 2016 or later** (recommended)
3. Navigate through the sheets:
   - `Raw Data` — original dataset
   - `Cleaned Data` — processed and analysis-ready data
   - `Pivot Tables` — summarized views of the data
   - `Dashboard` — final visual summary with charts and slicers

> **Note:** Enable macros if prompted, and ensure Excel's Analysis ToolPak is active for full functionality.

## 📋 Dataset Description

The dataset contains transactional sales records from Vrinda Store covering orders placed across multiple e-commerce platforms. Key columns include:

| Column | Description |
|--------|-------------|
| Order ID | Unique identifier for each order |
| Customer ID | Unique identifier for each customer |
| Gender | Customer gender (Men / Women) |
| Age | Customer age |
| Date | Order date |
| Status | Order status (Delivered, Returned, Cancelled, etc.) |
| Channel | Sales platform (Amazon, Flipkart, Meesho, etc.) |
| Category | Product category |
| Qty | Quantity ordered |
| Amount | Order value (INR) |
| State | Delivery state |
